# 浩渺星途

一个开源共创的修仙小说宇宙。

## 这是什么

《浩渺星途》是一个**开源共创**的修仙小说项目。我们试图探索一种新的创作模式：由核心团队维护世界观与故事主线，由无数创作者共同填充细节、提供版本，由读者投票选出最佳版本，最终形成一个持续进化的“正典”。

故事分为**现代篇**与**修仙世界篇**。现代篇讲述一个程序员在末法时代修炼、越界、被清除、告别、消失的故事。修仙世界篇则是他在另一个世界的重生与新一轮筛选。

## 核心理念

- **共创**：任何人都是创作者。写一个场景、一段对话、一个细节，即可参与。
- **共赢**：创作者获得署名权与永久收益分成权。核心团队拥有IP所有权。
- **开源**：阅读器开源，创作过程透明，收益分配公开。
- **进化**：同一场景可有多个版本，读者投票，优胜劣汰。

## 如何参与

- **阅读**：免费阅读正典最终版本。
- **投票**：为你喜欢的版本投票。
- **创作**：购买架构阅读权，提交你的版本，进入正典即可获得收益分成。
- **传播**：分享项目，吸引更多人参与。
